# hopeana

## Process maps

`process-maps/` is a shared, Miro-style board for mapping back-office processes: sticky notes, steps, decisions, swimlanes and connectors, with owner, system, time and pain points on every step, edited by the whole team at once.

It is built as a self-contained module on Peggy's stack and is meant to move into Peggy. This repository is its staging home until then. Everything you need, including how to run it, deploy it, and move it into Peggy, is in [process-maps/README.md](process-maps/README.md).
